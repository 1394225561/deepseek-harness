# Agent Note: 复用生态声明

Status: implemented

[English](2026-10-05-reuse-ecosystem-declarations.md) | 中文

## 问题

自定义声明可能重复包生态已经定义的信息。将既有元数据转换成独立维护的字段，会引入额外的校验和解释规则。目录与用户界面需要选取数据，但第二份由作者维护的声明可能与原始声明不一致。

## 决策

既有生态声明、格式和含义满足 DSH 需求时，贡献者必须复用它们。读取器实现必须使用持续维护的解析器和校验器。目录与用户界面必须从原始声明派生数据。生成的投影可以省略未使用的字段，或归一化显示数据，但必须保留原始含义。所属包的 README 或生成器的 JSDoc 记录投影规则。

新增字段或改变含义时，必须说明尚未满足的具体需求，并记录与生态规则的差异。作者定义 npm 包元数据时，复用 npm 的包身份、版本与范围语法，以及人员字段。DSH 特有的组合、本地化显示数据和宿主约束的强制执行仍须明确的 DSH 规则。

[依赖政策](2026-07-26-dependencies-over-hand-rolling.zh.md)负责依赖选择。[公共 manifest 决策](../architecture/2026-09-10-public-package-manifest.zh.md)负责选取的 npm 字段与 DSH 声明。这些决策继续负责各自的范围；本政策负责声明及其解释的复用。

## 考虑过的替代方案

**复用字段名称，却独立定义含义。** 如果没有说明需求便改变熟悉声明的解释方式，既有工具和作者就无法依赖这些声明。

**完整复制生态元数据，不做适配。** 消费方需要不同的字段子集和显示格式。记录规则的生成投影保留原始声明，无需每个消费方都保留未使用的数据。

## 后果

[根指令](../../../../AGENTS.md#conventions)要求复用声明并记录差异。评审检查原始声明、复用的解析器或校验器，以及每种投影的含义。本政策不增加安装器行为，也不迁移包元数据。
